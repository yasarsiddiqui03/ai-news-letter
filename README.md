# AI NEWS LETTER ⚡

> Production-grade, real-time AI news curation platform built with Flask, SQLite, and vanilla modern JavaScript. Delivers exactly 21 fresh, non-repeating news briefings per load across 7 frontier categories, AI summaries via Gemini, persistent OTP authentication (Phone/Email), and a 2FA TOTP protected administrator console.

---

## 🌟 Key Features

1. **Start Page (`/`)**
   - Full-screen animated hero with canvas particle dynamics and glowing ambient gradients.
   - Smooth, seamless page transition into the Main Feed on clicking **Explore**.

2. **Main Feed (`/home.html`)**
   - **Exactly 21 Cards Per View**: Responsive 3 columns on desktop, 2 on tablet, and 1 on mobile.
   - **No-Repeat Guarantee**: Server-side visitor tracking ensuring unseen articles on every refresh.
   - **7 Frontier Categories**: Technology, AI, Science, Startups, Business, Cyber Security, World News (plus All).
   - **Zero Page Reloads**: Refresh button and category switching fetch via asynchronous AJAX while animating skeleton loaders.
   - **Live Search**: Instant backend search with debouncing.
   - **Saved Articles Drawer**: One-click star bookmarking persisting across sessions in SQLite.
   - **AI News Summarizer**: Paste any long publication or research paper for instant extraction into a headline, 5–7 bullet points, and an executive synthesis paragraph.

3. **Article Detail (`/article.html?id=...`)**
   - Complete article overview with verified source metadata and publication date.
   - **AI-Generated Summary**: Generated using Gemini API and cached in SQLite to prevent duplicate latency and quota usage.
   - **Read More**: Secure external tab redirection (`rel="noopener noreferrer"`).
   - **Activity Logging**: Automatically logs user identifier or anonymous visitor IP to the Admin Activity table.

4. **Strict Authentication & Security**
   - **Separate Signup & Login Flows**: Unregistered users cannot log in without signing up first.
   - **Multi-Channel OTP**: Phone SMS (E.164 format) and Email verification.
   - **Cryptographic Lifecycle**: 6-digit cryptographic OTPs, SHA-256 hashed in DB, 5-minute expiry, max 5 attempts, 30-second cooldown timer, and rate limits.
   - **Persistent Session**: 7-day persistent JWT issued in secure `httpOnly` cookie and client storage.

5. **Administrator Portal with 2FA TOTP**
   - Visible to all visitors, but non-admins receive a clear restricted access modal.
   - Protected with Bcrypt password hashing + Google Authenticator TOTP 2FA (`pyotp`).
   - One-time QR code provisioning screen to link any standard Authenticator app.
   - **Registered Users Console**: View IDs, channels, contact identifiers, signup timestamps, and last login dates.
   - **User Activity Audit**: Searchable and filterable activity table showing visitors, article titles, URLs, and access timestamps.

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3 (Custom Design System, Glassmorphism, CSS Grid), Vanilla ES6+ JavaScript (Zero frameworks).
- **Backend**: Python 3.10+, Flask 3.0.3, SQLite (WAL mode enabled), PyJWT, PyOTP, QRCode, Bcrypt.
- **APIs**: Google News RSS / Google Custom Search JSON API, Google Gemini API.

## 🚀 Quick Start Instructions

### 1. Prerequisites
Ensure Python 3.10 or higher is installed on your system.

### 2. Install Dependencies
```bash
python -m pip install -r backend/requirements.txt
```

### 3. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
*(On Windows PowerShell: `Copy-Item .env.example .env`)*

The system includes pre-configured development defaults. Optional external keys (Google CSE, Gemini API, Twilio, SMTP) can be added as needed. When keys are not supplied, the application automatically uses its intelligent NLP summarizer and development OTP console fallback.

### 4. Start the Application
Run the Flask server:
```bash
python backend/app.py
```

### 5. Access the Application
Open your browser and navigate to:
- **Start Page**: [http://localhost:5000/](http://localhost:5000/)
- **Main Feed**: [http://localhost:5000/home.html](http://localhost:5000/home.html)
- **Article Reader**: [http://localhost:5000/article.html](http://localhost:5000/article.html)

## 🛡️ Security & Reliability

- **SQL Injection Prevention**: Parameterized queries across SQLite operations.
- **XSS Prevention**: DOM text escaping and safe element construction in vanilla JS.
- **Password Security**: Strong Bcrypt hashing with salted cost factors.
- **Brute-Force Protection**: 5-attempt threshold and 30-second resend cooldown on OTP codes.
- **Persistent Sessions**: Secure `httpOnly` JWT cookies with 7-day retention.
